# Phase 1 Badge Pet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship firmware that turns the M5Stack StopWatch badge into a Tamagotchi whose creature is the procedurally animated Charming mascot, following the spec's harsh-but-recoverable rules.

**Architecture:**
- The pet simulation is a pure C++ module, unit-tested on the Mac with simulated time.
- Device code (renderer, input, scenes, storage, power) sits on top of it.
- The Arduino sketch wires everything together with M5Unified and M5GFX.
- Rendering draws into one PSRAM canvas and pushes only the dirty rectangle to the AMOLED.

**Tech Stack:** arduino-cli, M5Stack ESP32 core 3.3.9 (board `m5stack_stopwatch`), M5Unified 0.2.25, M5GFX 0.2.32, C++17, doctest (host tests), Python 3 with freetype-py and esptool 4.x (tools).

**Spec:** `docs/superpowers/specs/2026-10-12-phase1-pet-design.md`

## Global Constraints

- **Board.** FQBN is `m5stack:esp32:m5stack_stopwatch:PartitionScheme=app3M_fat9M_16MB`. Never build with any other partition scheme.
- **Conference profile.**
  - Never call `FFat.begin(true)`.
  - Never mount or write the `ffat` partition.
  - Never run `esptool erase_flash`.
- **Backup.** A full 16 MB flash backup must exist in `backups/` (gitignored) before the first upload.
- **Port.** The upload port defaults to `/dev/cu.usbmodem101`. Every script must allow overriding it with `PORT=`.
- **Versions.** M5Unified must be 0.2.15 or newer, M5GFX 0.2.21 or newer, and the M5Stack core 3.3.7 or newer. This plan pins 0.2.25, 0.2.32 and 3.3.9.
- **Screen.**
  - 466×466 round, background pure black `#000000`.
  - On the pet screen only the mascot (and its effects) is drawn.
  - Text appears only on Menu, Status, Name tag, Message and Gone, or for an event message.
- **Fonts.**
  - Silkscreen for headlines.
  - Inter for body text.
  - Geist Mono for small labels.
  - No Lora, no Instrument Serif, and none of Charming's paper colors or cards.
- **Mascot colors.** Coral `#f77448`, ink `#151410`, cream highlight `#fbf0d9`. These come from `charming-mark.svg`.
- **Overlap.** Content never overlaps the mascot. Whenever content is shown, the mascot uses pose `ASIDE` (cx 233, cy 378, scale 0.3).
- **Name tag text.** "HELLO, I'M" / "AKHILESH" / "Founding Engineer @Charming".
- **Night hours.** 23:00 to 07:00.
- **Tuning.** All tuning numbers live in `firmware/badge-pet/src/pet/PetConfig.h`.
- **Git.** No Claude attribution or session URLs in commits.

## Review Focus

1. **RTC lost or reset** (year < 2025 after a battery drain), **or the clock jumps backwards.** The pet must neither freeze for years nor simulate a negative gap. Task 6 covers the clock going backwards; Task 11 covers seeding the clock.
2. **Badge left off for weeks.** Catch-up must be bounded (30 days, so boot isn't stuck for minutes), must end in a recoverable state, and recovery must take 5 sessions. Covered by a Task 6 test.
3. **Corrupt or old saved state in NVS** (a struct-layout change after a firmware update, or power lost mid-write). It must start a new pet instead of crashing or loading garbage. Covered by a Task 6 decode test.
4. **Tap vs. stroke confusion.** A slow tap must not count as a stroke, and a short flick must not count as a tap. Covered by Task 8 gesture tests.
5. **Holding both buttons** must not also trigger the single-button hold actions (status screen, call-back). Covered by the Task 8 button arbiter test.

```cpp
#include <M5Unified.h>
static M5Canvas canvas(&M5.Display);
void setup() {
  auto cfg = M5.config();
  M5.begin(cfg);
  Serial.begin(115200);
  canvas.setPsram(true);
  canvas.setColorDepth(16);
  bool ok = canvas.createSprite(M5.Display.width(), M5.Display.height());
  Serial.printf("board=%d w=%d h=%d psram=%u sprite=%d imu=%d rtc=%d touch=%d\n",
    (int)M5.getBoard(), M5.Display.width(), M5.Display.height(), (unsigned)ESP.getPsramSize(),
    ok, M5.Imu.isEnabled(), M5.Rtc.isEnabled(), M5.Touch.isEnabled());
}
void loop() {
  static uint32_t frames = 0, t0 = millis();
  M5.update();
  canvas.fillScreen(TFT_BLACK);
  canvas.fillSmoothCircle(233 + (int)(sinf(millis() / 500.f) * 100), 233, 60, 0xF77448u);
  M5.Display.startWrite();
  canvas.pushSprite(0, 0);
  M5.Display.endWrite();
  if (M5.BtnA.wasClicked()) { M5.Power.setVibration(160); delay(60); M5.Power.setVibration(0); Serial.println("A"); }
  if (M5.BtnB.wasClicked()) Serial.println("B");
  if (++frames == 60) { Serial.printf("fps=%.1f\n", 60000.f / (millis() - t0)); frames = 0; t0 = millis(); }
}
```

```cpp
#pragma once
#include <stdint.h>
namespace pet {
inline int64_t daysFromCivil(int y, int m, int d) {
  y -= m <= 2;
  const int era = (y >= 0 ? y : y - 399) / 400;
  const int yoe = y - era * 400;
  const int doy = (153 * (m + (m > 2 ? -3 : 9)) + 2) / 5 + d - 1;
  const int doe = yoe * 365 + yoe / 4 - yoe / 100 + doy;
  return (int64_t)era * 146097 + doe - 719468;
}
inline int64_t localMinutes(int y, int mo, int d, int h, int mi) {
  return (daysFromCivil(y, mo, d) - daysFromCivil(2000, 1, 1)) * 1440 + h * 60 + mi;
}
inline bool plausibleYear(int y) { return y >= 2025 && y <= 2099; }
inline int hourOf(int64_t m) { return (int)(((m / 60) % 24 + 24) % 24); }
}
```

```cpp
#include "PetRules.h"
#include "PetConfig.h"
#include <algorithm>
namespace pet {
using namespace cfg;

static float clamp100(float v) { return v < 0 ? 0 : (v > 100 ? 100 : v); }
static void clampAll(PetState& s) {
  s.food = clamp100(s.food); s.energy = clamp100(s.energy); s.joy = clamp100(s.joy);
  s.hygiene = clamp100(s.hygiene); s.trust = clamp100(s.trust);
  s.discipline = clamp100(s.discipline); s.spoil = clamp100(s.spoil);
}

bool isNight(int64_t m) { const int h = hourOf(m); return h >= NIGHT_START_H || h < NIGHT_END_H; }

PetState newPet(int64_t nowMin) {
  PetState s;
  s.lastMin = nowMin;
  s.rng = (uint32_t)(nowMin * 2654435761u) | 1u;
  return s;
}

uint32_t tickMinute(PetState& s) {
  uint32_t ev = 0;
  s.lastMin++;
  const float f = s.asleep ? SLEEP_DECAY : 1.0f;
  const float k = s.sick ? SICK_DECAY : 1.0f;
  s.food    -= 100.0f / FOOD_EMPTY_MIN * f * k;
  s.joy     -= 100.0f / JOY_EMPTY_MIN * f * k;
  s.hygiene -= 100.0f / HYGIENE_EMPTY_MIN * f * k;
  if (s.asleep) s.energy += 100.0f / ENERGY_REFILL_MIN;
  else          s.energy -= 100.0f / ENERGY_EMPTY_MIN;
  clampAll(s);
  return ev;
}

uint32_t catchUp(PetState& s, int64_t nowMin) {
  uint32_t ev = 0;
  while (s.lastMin < nowMin) ev |= tickMinute(s);
  return ev;
}

uint32_t applyCare(PetState& s, Care, int64_t nowMin) { return catchUp(s, nowMin); }
bool callBack(PetState&, int64_t) { return false; }
bool togglePause(PetState&, int64_t) { return false; }
}
```

The "sleep slows hunger" test starts at `energy = 40`. That way the full-energy auto-wake added in Task 5 cannot wake the pet mid-test (energy ends at 90), and energy never sits at 0 long enough to trigger Task 3's sickness rule.

```cpp
#include "SaveCodec.h"
#include <string.h>
namespace pet {
static uint32_t crc32(const uint8_t* p, size_t n) {
  uint32_t c = 0xFFFFFFFFu;
  for (size_t i = 0; i < n; i++) { c ^= p[i]; for (int k = 0; k < 8; k++) c = (c >> 1) ^ (0xEDB88320u & (0u - (c & 1u))); }
  return ~c;
}
size_t encodeSave(const PetState& s, uint8_t* out, size_t cap) {
  if (cap < SAVE_SIZE) return 0;
  const uint16_t ver = SAVE_VERSION, size = (uint16_t)sizeof(PetState);
  memcpy(out, &SAVE_MAGIC, 4); memcpy(out + 4, &ver, 2); memcpy(out + 6, &size, 2);
  memcpy(out + 8, &s, sizeof(PetState));
  const uint32_t crc = crc32(out, 8 + sizeof(PetState));
  memcpy(out + 8 + sizeof(PetState), &crc, 4);
  return SAVE_SIZE;
}
bool decodeSave(const uint8_t* in, size_t n, PetState& out) {
  if (n != SAVE_SIZE) return false;
  uint32_t magic, crc; uint16_t ver, size;
  memcpy(&magic, in, 4); memcpy(&ver, in + 4, 2); memcpy(&size, in + 6, 2);
  if (magic != SAVE_MAGIC || ver != SAVE_VERSION || size != sizeof(PetState)) return false;
  memcpy(&crc, in + 8 + sizeof(PetState), 4);
  if (crc != crc32(in, 8 + sizeof(PetState))) return false;
  memcpy(&out, in + 8, sizeof(PetState));
  return true;
}
}
```

```python
def cubics(d):
    nums = [float(x) for x in re.findall(r"-?\d+(?:\.\d+)?", d)]
    start, rest = (nums[0], nums[1]), nums[2:]
    segs, p = [], start
    for i in range(0, len(rest) - 5, 6):
        c1, c2, e = (rest[i], rest[i+1]), (rest[i+2], rest[i+3]), (rest[i+4], rest[i+5])
        segs.append((p, c1, c2, e)); p = e
    return segs

def bez(s, t):
    (x0, y0), (x1, y1), (x2, y2), (x3, y3) = s
    u = 1 - t
    return (u**3*x0 + 3*u*u*t*x1 + 3*u*t*t*x2 + t**3*x3, u**3*y0 + 3*u*u*t*y1 + 3*u*t*t*y2 + t**3*y3)

def resample(d, n, closed):
    dense = []
    for s in cubics(d):
        for k in range(200):
            dense.append(bez(s, k / 200))
    dense.append(bez(cubics(d)[-1], 1.0))
    lengths = [0.0]
    for a, b in zip(dense, dense[1:]):
        lengths.append(lengths[-1] + math.dist(a, b))
    total, out, j = lengths[-1], [], 0
    count = n if closed else n - 1
    for i in range(n):
        target = total * i / count
        while j < len(lengths) - 2 and lengths[j + 1] < target:
            j += 1
        seg = lengths[j + 1] - lengths[j] or 1
        t = (target - lengths[j]) / seg
        a, b = dense[j], dense[j + 1]
        out.append((a[0] + (b[0] - a[0]) * t, a[1] + (b[1] - a[1]) * t))
    return out
```

`tools/make_fonts.py`:
```python
"""Convert TTFs to M5GFX VLW font arrays. VLW: 6 BE int32 header, 7 BE int32 per glyph, 8-bit alpha bitmaps."""
import struct, sys, freetype

FONTS = [  # (symbol, ttf, pixel size, monochrome)
    ("FONT_HEAD48", "tools/fonts/Silkscreen-Regular.ttf", 48, True),
    ("FONT_HEAD32", "tools/fonts/Silkscreen-Regular.ttf", 32, True),
    ("FONT_BODY20", "tools/fonts/Inter.ttf", 20, False),
    ("FONT_MONO15", "tools/fonts/GeistMono.ttf", 15, False),
]

def glyph_bitmap(bm, mono):
    w, h, pitch, buf = bm.width, bm.rows, bm.pitch, bm.buffer
    out = bytearray()
    for y in range(h):
        row = buf[y * pitch:(y + 1) * pitch]
        if mono:
            for x in range(w):
                out.append(255 if (row[x >> 3] >> (7 - (x & 7))) & 1 else 0)
        else:
            out.extend(row[:w])
    return bytes(out)

def vlw(path, px, mono):
    face = freetype.Face(path)
    face.set_pixel_sizes(0, px)
    flags = freetype.FT_LOAD_RENDER | (freetype.FT_LOAD_TARGET_MONO if mono else 0)
    metas, bitmaps = [], []
    for cp in range(0x20, 0x7F):
        face.load_char(chr(cp), flags)
        g = face.glyph
        bm = glyph_bitmap(g.bitmap, mono)
        metas.append(struct.pack(">7i", cp, g.bitmap.rows, g.bitmap.width, g.advance.x >> 6, g.bitmap_top, g.bitmap_left, 0))
        bitmaps.append(bm)
    asc, desc = face.size.ascender >> 6, -(face.size.descender >> 6)
    header = struct.pack(">6i", len(metas), 11, px, 0, asc, desc)
    return header + b"".join(metas) + b"".join(bitmaps)

if __name__ == "__main__":
    with open(sys.argv[1], "w") as f:
        f.write("// Generated by tools/make_fonts.py. Fonts: Silkscreen, Inter, Geist Mono (SIL OFL 1.1, see tools/fonts).\n#pragma once\n#include <stdint.h>\n")
        for sym, path, px, mono in FONTS:
            data = vlw(path, px, mono)
            body = ",".join(str(b) for b in data)
            f.write(f"static const uint8_t {sym}[{len(data)}] = {{{body}}};\n")
```

```cpp
namespace render {
constexpr int SCREEN = 466, CENTER = 233, RADIUS = 233;
struct Rect {
  int16_t x = 0, y = 0, w = 0, h = 0;
  bool empty() const { return w <= 0 || h <= 0; }
  Rect unite(const Rect& o) const {
    if (empty()) return o; if (o.empty()) return *this;
    int x0 = std::min(x, o.x), y0 = std::min(y, o.y);
    int x1 = std::max(x + w, o.x + o.w), y1 = std::max(y + h, o.y + o.h);
    return {(int16_t)x0, (int16_t)y0, (int16_t)(x1 - x0), (int16_t)(y1 - y0)};
  }
  Rect padded(int p) const { return {(int16_t)(x - p), (int16_t)(y - p), (int16_t)(w + 2 * p), (int16_t)(h + 2 * p)}; }
  Rect clippedEven() const {   // clamp to the screen and align x/w to even pixels (AMOLED column pairs)

    return {(int16_t)x0, (int16_t)y0, (int16_t)(x1 - x0), (int16_t)(y1 - y0)};
```

```cpp
#include <math.h>
namespace render {
static void line(M5Canvas& c, float x0, float y0, float x1, float y1, float r, uint32_t col) {
  c.drawWideLine((int32_t)x0, (int32_t)y0, (int32_t)x1, (int32_t)y1, r, col);
}
static void arc(M5Canvas& c, float cx, float cy, float rad, float a0, float a1, float r, uint32_t col) {
  const int n = 8;
  float px = cx + cosf(a0) * rad, py = cy + sinf(a0) * rad;
  for (int i = 1; i <= n; i++) {
    const float a = a0 + (a1 - a0) * i / n, x = cx + cosf(a) * rad, y = cy + sinf(a) * rad;
    line(c, px, py, x, y, r, col); px = x; py = y;
  }
}
void drawFace(M5Canvas& c, Expression e, float x, float y, float s, uint32_t ms, bool blink) {
  const float ex = 21 * s, r = 9 * s, PI_F = 3.14159265f;
  for (int side = -1; side <= 1; side += 2) {
    const float cx = x + side * ex;
    switch (e) {
      case Expression::Happy:   arc(c, cx, y + 6 * s, 11 * s, PI_F * 1.1f, PI_F * 1.9f, r * 0.7f, INK); break;
      case Expression::Sleep:   arc(c, cx, y - 4 * s, 10 * s, PI_F * 0.15f, PI_F * 0.85f, r * 0.6f, INK); break;
      case Expression::Sick:    line(c, cx - 9 * s, y + 2 * s, cx + 9 * s, y + 6 * s, r * 0.7f, INK); break;
      case Expression::Sleepy:  line(c, cx - 9 * s, y + 2 * s, cx + 9 * s, y + 2 * s, r * 0.6f, INK); break;
      case Expression::Grumpy:
        line(c, cx - 10 * s, y - 2 * s, cx + 10 * s, y - 2 * s, r * 0.55f, INK);
        line(c, cx, y, cx, y + 5 * s, r, INK); break;
      case Expression::Tantrum:
        line(c, cx - side * 8 * s, y - 7 * s, cx + side * 8 * s, y, r * 0.6f, INK);
```

```cpp
#include "Mascot.h"

static_assert(FLAME_N == MASCOT_N, "regenerate flame_points.h");

static float hash01(uint32_t v) { v ^= v >> 16; v *= 0x7feb352du; v ^= v >> 15; v *= 0x846ca68bu; v ^= v >> 16; return (v & 0xFFFFFF) / 16777216.0f; }

void Mascot::poke(int x, int y) {
  for (int i = 0; i < MASCOT_N; i++) {
    const float px = pose_.cx + (FLAME_PTS[i][0] - 256) * pose_.scale, py = pose_.cy + (FLAME_PTS[i][1] - 256) * pose_.scale;
    const float dx = px - x, dy = py - y, d = sqrtf(dx * dx + dy * dy) + 0.001f, k = fmaxf(0, 1 - d / 160);
    velX_[i] += dx / d * 22 * k; velY_[i] += dy / d * 22 * k;
  }
  hop_ = 1;
}

bool Mascot::hitTest(int x, int y) const {
  return x >= bounds_.x && x < bounds_.x + bounds_.w && y >= bounds_.y && y < bounds_.y + bounds_.h;
}

void Mascot::update(uint32_t ms) {
  float dt = lastMs_ ? (ms - lastMs_) / 1000.0f : 0.016f;
  if (dt > 0.05f) dt = 0.05f;
  lastMs_ = ms;
  const float steps = dt * 60, damp = powf(0.86f, steps);
  for (int i = 0; i < MASCOT_N; i++) {
    velX_[i] += -offX_[i] * 0.18f * steps; velY_[i] += -offY_[i] * 0.18f * steps;
    velX_[i] *= damp; velY_[i] *= damp;
    offX_[i] += velX_[i] * steps; offY_[i] += velY_[i] * steps;
  }
  hop_ *= powf(0.92f, steps);
  const float e = fminf(1, dt * 6);
  pose_.cx += (target_.cx - pose_.cx) * e; pose_.cy += (target_.cy - pose_.cy) * e; pose_.scale += (target_.scale - pose_.scale) * e;
  if (ms > nextWander_) {
    wanderX_ = ((rnd() % 1000) / 500.0f - 1) * 0.5f; wanderY_ = ((rnd() % 1000) / 500.0f - 1) * 0.3f;
    nextWander_ = ms + 900 + rnd() % 1800;
  }
  const float tx = lookTX_ + wanderX_ * (1 - fminf(1, fabsf(lookTX_))), ty = lookTY_ + wanderY_ * (1 - fminf(1, fabsf(lookTY_)));
  const float le = fminf(1, dt * 8);
  lookX_ += (tx - lookX_) * le; lookY_ += (ty - lookY_) * le;
  if (!blinking_ && ms > nextBlink_) { blinking_ = true; blinkStart_ = ms; }
  if (blinking_ && ms - blinkStart_ > 160) { blinking_ = false; nextBlink_ = ms + 2200 + rnd() % 3000; }
  boil_ = ms / 110 + 7;
}

void Mascot::deform(float x, float y, int i, uint32_t ms, float& ox, float& oy) const {
  const float t = (float)ms;
  const bool slow = expr_ == Expression::Sleep;
  const float br = sinf(t / (slow ? 1400.0f : 650.0f)) * (slow ? 0.035f : 0.022f);
  float sx = 1 - br * 0.6f, sy = 1 + br, hopY = 0;
  switch (expr_) {
    case Expression::Happy: { const float b = fabsf(sinf(t / 230)); hopY = -b * 22; sy += b < 0.25f ? -0.08f : 0.03f; sx += b < 0.25f ? 0.06f : -0.02f; break; }
    case Expression::Hungry: { const float b = fmaxf(0, sinf(t / 180)) * (sinf(t / 1300) > 0.3f ? 1 : 0); hopY = -b * 12; break; }
    case Expression::Sick: sy *= 0.9f; sx *= 1.07f; break;
    case Expression::Tantrum: sx += sinf(t / 45) * 0.03f; hopY = -fabsf(sinf(t / 120)) * 10; break;
    case Expression::Sad: case Expression::Sleepy: sy *= 0.95f; sx *= 1.03f; break;
    default: break;
  }
  const float g = 1 + growth_ * 0.04f;
  sx *= g; sy *= g;
  hopY -= hop_ * 10;
  float nx = 256 + (x - 256) * sx, ny = 459 + (y - 459) * sy + hopY;
  if (y < 170) {
    const float w = (170 - y) / 128, amp = slow ? 0.3f : (expr_ == Expression::Sick ? 0.15f : 1.0f);
    nx += sinf(t / 160 + y / 30) * 7 * w * amp;
    if (expr_ == Expression::Sick) nx += w * w * 26;
  }
  nx += lookX_ * 12 * (459 - y) / 400;
  nx += (hash01(boil_ * 131 + i * 17) - 0.5f) * 2.2f;
  ny += (hash01(boil_ * 131 + i * 17 + 1) - 0.5f) * 2.2f;
  ox = pose_.cx + (nx - 256) * pose_.scale;
  oy = pose_.cy + (ny - 256) * pose_.scale;
}

static void fillPoly(M5Canvas& c, const float* xs, const float* ys, int n, uint32_t col, int ymin, int ymax) {
  float nodes[32];
  for (int y = ymin; y <= ymax; y++) {
    int cnt = 0; const float fy = y + 0.5f;
    for (int i = 0, j = n - 1; i < n; j = i++) {
      if ((ys[i] < fy && ys[j] >= fy) || (ys[j] < fy && ys[i] >= fy)) {
        if (cnt < 32) nodes[cnt++] = xs[i] + (fy - ys[i]) / (ys[j] - ys[i]) * (xs[j] - xs[i]);
      }
    }
    for (int a = 1; a < cnt; a++) { float v = nodes[a]; int b = a - 1; while (b >= 0 && nodes[b] > v) { nodes[b + 1] = nodes[b]; b--; } nodes[b + 1] = v; }
    for (int k = 0; k + 1 < cnt; k += 2) {
      const int x0 = (int)lroundf(nodes[k]), x1 = (int)lroundf(nodes[k + 1]);
      if (x1 > x0) c.drawFastHLine(x0, y, x1 - x0, col);
    }
  }
}

Rect Mascot::draw(M5Canvas& c, uint32_t ms) {
  float px[MASCOT_N], py[MASCOT_N];
  for (int i = 0; i < MASCOT_N; i++) {
    deform(FLAME_PTS[i][0], FLAME_PTS[i][1], i, ms, px[i], py[i]);
    px[i] += offX_[i]; py[i] += offY_[i];
  }
  constexpr int SUB = 3, M = MASCOT_N * SUB;
  float qx[M], qy[M];
  float minX = 1e9f, minY = 1e9f, maxX = -1e9f, maxY = -1e9f;
  for (int i = 0; i < MASCOT_N; i++) {
    const int p = (i + MASCOT_N - 1) % MASCOT_N, n = (i + 1) % MASCOT_N;
    const float ax = (px[p] + px[i]) / 2, ay = (py[p] + py[i]) / 2, ex = (px[i] + px[n]) / 2, ey = (py[i] + py[n]) / 2;
    for (int k = 0; k < SUB; k++) {
      const float t = (float)k / SUB, u = 1 - t;
      const float x = u * u * ax + 2 * u * t * px[i] + t * t * ex, y = u * u * ay + 2 * u * t * py[i] + t * t * ey;
      qx[i * SUB + k] = x; qy[i * SUB + k] = y;
      minX = fminf(minX, x); maxX = fmaxf(maxX, x); minY = fminf(minY, y); maxY = fmaxf(maxY, y);
    }
  }
  const float s = pose_.scale;
  c.fillEllipse((int32_t)pose_.cx, (int32_t)(pose_.cy + 206 * s), (int32_t)(120 * s), (int32_t)(14 * s), SHADOW);
  const uint32_t body = expr_ == Expression::Sick ? CORAL_SICK : CORAL;
  fillPoly(c, qx, qy, M, body, (int)floorf(minY), (int)ceilf(maxY));
  const float sr = 12 * s * 1.15f * 0.5f + 0.5f;
  for (int i = 0; i < M; i++) {
    const int j = (i + 1) % M;
    c.drawWideLine((int32_t)qx[i], (int32_t)qy[i], (int32_t)qx[j], (int32_t)qy[j], sr, INK);
  }
  for (int i = 0; i < M; i += 2) {
    const int j = (i + 2) % M;
    c.drawWideLine((int32_t)qx[i], (int32_t)qy[i], (int32_t)qx[j], (int32_t)qy[j], 0.6f, RIM);
  }
  if (expr_ != Expression::Sick) {
    float hx0 = 0, hy0 = 0;
    for (int i = 0; i < HL_N; i++) {
      float hx, hy; deform(HL_PTS[i][0], HL_PTS[i][1], (i * 7) % MASCOT_N, ms, hx, hy);
      if (i) c.drawWideLine((int32_t)hx0, (int32_t)hy0, (int32_t)hx, (int32_t)hy, 6 * s, CREAM);
      hx0 = hx; hy0 = hy;
    }
  }
  float fx, fy; deform(260, 268, 0, ms, fx, fy);
  drawFace(c, expr_, fx + lookX_ * 14 * s, fy + lookY_ * 10 * s, s, ms, blinking_);
  bounds_ = Rect{(int16_t)minX, (int16_t)minY, (int16_t)(maxX - minX + 1), (int16_t)(pose_.cy + 222 * s - minY)}.padded((int)(sr + 3));
  return bounds_;
}
```

The button arbiter replaces M5Unified's per-button click and hold handling. That way "both held" is decided in one place, and a hold that turns into a both-hold never also fires as a single hold.

`firmware/badge-pet/src/input/Gesture.h`:
```cpp
#pragma once
#include <stdint.h>
namespace input {
enum class Gesture : uint8_t { None, Tap, Stroke };
constexpr float STROKE_MIN_PATH = 120;  constexpr uint32_t STROKE_MIN_MS = 150;
constexpr float TAP_MAX_MOVE = 18;      constexpr uint32_t TAP_MAX_MS = 450;
class GestureTracker {
 public:
  void begin(int x, int y, uint32_t ms) { active_ = true; sx_ = lx_ = x; sy_ = ly_ = y; t0_ = ms; path_ = 0; }
  void move(int x, int y);
  Gesture end(uint32_t ms);
  bool active() const { return active_; }
 private:
  bool active_ = false; int sx_ = 0, sy_ = 0, lx_ = 0, ly_ = 0; uint32_t t0_ = 0; float path_ = 0;
};
}
```

`firmware/badge-pet/src/input/Gesture.cpp`:
```cpp
#include "Gesture.h"
#include <math.h>
namespace input {
void GestureTracker::move(int x, int y) {
  if (!active_) return;
  path_ += sqrtf((float)((x - lx_) * (x - lx_) + (y - ly_) * (y - ly_)));
  lx_ = x; ly_ = y;
}
Gesture GestureTracker::end(uint32_t ms) {
  if (!active_) return Gesture::None;
  active_ = false;
  const uint32_t dur = ms - t0_;
  const float disp = sqrtf((float)((lx_ - sx_) * (lx_ - sx_) + (ly_ - sy_) * (ly_ - sy_)));
  if (path_ >= STROKE_MIN_PATH && dur >= STROKE_MIN_MS) return Gesture::Stroke;
  if (disp <= TAP_MAX_MOVE && path_ <= TAP_MAX_MOVE * 2 && dur <= TAP_MAX_MS) return Gesture::Tap;
  return Gesture::None;
}
}
```

```cpp
namespace input {
bool ShakeDetector::feed(float g, uint32_t ms) {
  if (g < 1.3f) { armed_ = true; return false; }
  if (!armed_ || g < 2.0f) return false;
  armed_ = false;
  peaks_[0] = peaks_[1]; peaks_[1] = peaks_[2]; peaks_[2] = ms;
  if (n_ < 3) n_++;
  if (n_ == 3 && peaks_[2] - peaks_[0] <= 800) { n_ = 0; return true; }
  return false;
}
}
```

```cpp
#include <stdint.h>
namespace input {
enum class ButtonEvent : uint8_t { None, AClick, BClick, AHold, BHold, BothHold };
constexpr uint32_t HOLD_MS = 1000, BOTH_HOLD_MS = 3000, BOTH_GRACE_MS = 600;
class ButtonArbiter {
 public:
  ButtonEvent update(bool a, bool b, uint32_t ms);
 private:
  bool aDown_ = false, bDown_ = false, consumed_ = false, both_ = false;
  uint32_t aT_ = 0, bT_ = 0, bothT_ = 0;
};
}
```

`firmware/badge-pet/src/input/ButtonArbiter.cpp`:
```cpp
#include "ButtonArbiter.h"
namespace input {
ButtonEvent ButtonArbiter::update(bool a, bool b, uint32_t ms) {
  ButtonEvent ev = ButtonEvent::None;
  if (a && !aDown_) aT_ = ms;
  if (b && !bDown_) bT_ = ms;
  if (a && b && !both_) { both_ = true; bothT_ = ms; }
  if (both_) {
    if (a && b && !consumed_ && ms - bothT_ >= BOTH_HOLD_MS) { consumed_ = true; ev = ButtonEvent::BothHold; }
  } else if (!consumed_) {
    // single holds wait out a grace window so a second button can still join
    if (a && !b && ms - aT_ >= HOLD_MS + BOTH_GRACE_MS) { consumed_ = true; ev = ButtonEvent::AHold; }
    if (b && !a && ms - bT_ >= HOLD_MS + BOTH_GRACE_MS) { consumed_ = true; ev = ButtonEvent::BHold; }
  }
  if (!a && aDown_ && !b && !consumed_ && !both_) ev = ButtonEvent::AClick;
  if (!b && bDown_ && !a && !consumed_ && !both_) ev = ButtonEvent::BClick;
  aDown_ = a; bDown_ = b;
  if (!a && !b) { consumed_ = false; both_ = false; }
  return ev;
}
}
```

With this design, a single hold fires at 1.6 s (1 s hold plus 0.6 s grace). The spec says "hold 1 s"; the grace window is what lets the both-buttons hold win without a stray single hold, so 1.6 s is the closest safe value. The commit message calls out this deviation so the user sees it.

```cpp
#pragma once
#include <stdint.h>
#include "Gesture.h"
#include "Shake.h"
#include "ButtonArbiter.h"
namespace input {
constexpr float TILT_SIGN_X = -1.0f, TILT_SIGN_Y = 1.0f;   // verified on device in Task 8 Step 6
struct InputFrame {
  ButtonEvent button = ButtonEvent::None;
  bool tap = false; int tapX = 0, tapY = 0;
  bool stroke = false, shake = false, any = false;
  float tiltX = 0, tiltY = 0;
};
class Input {
 public:
  void begin();
  InputFrame poll(uint32_t ms);
 private:
  GestureTracker gesture_; ShakeDetector shake_; ButtonArbiter buttons_;
  float tx_ = 0, ty_ = 0;
};
}
```

`firmware/badge-pet/src/input/Input.cpp`:
```cpp
#include "Input.h"
#include <M5Unified.h>
#include <math.h>
namespace input {
void Input::begin() {}
InputFrame Input::poll(uint32_t ms) {
  InputFrame f;
  f.button = buttons_.update(M5.BtnA.isPressed(), M5.BtnB.isPressed(), ms);
  if (M5.Touch.isEnabled()) {
    const auto d = M5.Touch.getDetail();
    if (d.wasPressed()) gesture_.begin(d.x, d.y, ms);
    else if (d.isPressed()) gesture_.move(d.x, d.y);
    if (d.wasReleased() && gesture_.active()) {
      const Gesture g = gesture_.end(ms);
      if (g == Gesture::Tap) { f.tap = true; f.tapX = d.x; f.tapY = d.y; }
      if (g == Gesture::Stroke) f.stroke = true;
    }
    if (d.isPressed()) f.any = true;
  }
  if (M5.Imu.update()) {
    const auto& imu = M5.Imu.getImuData();
    const float ax = imu.accel.x, ay = imu.accel.y, az = imu.accel.z;
    auto clamp1 = [](float v) { return v < -1 ? -1.0f : (v > 1 ? 1.0f : v); };
    tx_ += (clamp1(TILT_SIGN_X * ax / 0.5f) - tx_) * 0.2f;
    ty_ += (clamp1(TILT_SIGN_Y * ay / 0.5f) - ty_) * 0.2f;
    f.shake = shake_.feed(sqrtf(ax * ax + ay * ay + az * az), ms);
  }
  f.tiltX = tx_; f.tiltY = ty_;
  if (f.button != ButtonEvent::None || f.tap || f.stroke || f.shake || M5.BtnA.isPressed() || M5.BtnB.isPressed()) f.any = true;
  return f;
}
}
```

```cpp
#include "TextLayer.h"
#include "assets/fonts.h"
#include <math.h>
namespace render {
static const uint8_t* fontData(Font f) {
  switch (f) {
    case Font::Head48: return FONT_HEAD48;
    case Font::Head32: return FONT_HEAD32;
    case Font::Body20: return FONT_BODY20;
    default:           return FONT_MONO15;
  }
}
void TextLayer::use(M5Canvas& c, Font f) {
  if (loaded_ == (int)f) return;
  c.unloadFont();
  c.loadFont(fontData(f));
  loaded_ = (int)f;
}
int TextLayer::maxWidthAt(int y) {
  const float dy = fabsf((float)(y - CENTER));
  if (dy >= RADIUS - 20) return 0;
  return (int)(2 * sqrtf((float)(RADIUS - 20) * (RADIUS - 20) - dy * dy)) - 24;
}
Rect TextLayer::text(M5Canvas& c, Font f, const char* s, int y, uint32_t color) {
  if (!s || !*s) return {};
  use(c, f);
  c.setTextDatum(middle_center);
  c.setTextColor(color);
  const int w = c.textWidth(s), h = c.fontHeight();
  c.drawString(s, CENTER, y);
  return Rect{(int16_t)(CENTER - w / 2 - 2), (int16_t)(y - h / 2 - 2), (int16_t)(w + 4), (int16_t)(h + 4)};
}
Rect TextLayer::headline(M5Canvas& c, const char* s, int y, uint32_t color) {
  use(c, Font::Head48);
  if (c.textWidth(s) <= maxWidthAt(y)) return text(c, Font::Head48, s, y, color);
  return text(c, Font::Head32, s, y, color);
}
```

```cpp
namespace scenes {
void PlayGame::start(uint32_t ms) { t0_ = last_ = ms; x_ = 233; caught_ = 0; seed_ = ms | 1; sx_ = 140 + (ms % 190); sy_ = 70; }
void PlayGame::update(float tiltX, uint32_t ms) {
  const float dt = (ms - last_) / 1000.0f; last_ = ms;
  x_ += tiltX * 260 * dt;
  if (x_ < 130) x_ = 130; if (x_ > 336) x_ = 336;
  sy_ += 150 * dt;
  if (sy_ > 330) {
    if (sx_ > x_ - 45 && sx_ < x_ + 45) caught_++;
    seed_ = seed_ * 1664525u + 1013904223u;
    sx_ = 140 + (seed_ >> 8) % 190; sy_ = 70;
  }
}
```

```cpp
uint32_t Scenes::handle(const input::InputFrame& in, pet::PetState& s, int64_t now, uint32_t ms) {
  uint32_t ev = 0;
  auto care = [&](pet::Care c) { cared = true; return pet::applyCare(s, c, now); };
  if (in.any) lastInputMs_ = ms;
  if (s.life == pet::Life::Gone && scene_ != SceneId::Gone && scene_ != SceneId::Message) go(SceneId::Gone, ms);
  m_.setLook(in.tiltX, in.tiltY);
  if (in.button == ButtonEvent::BothHold && s.life != pet::Life::Gone) {
    const bool paused = pet::togglePause(s, now);
    display::Content k; k.title = paused ? "PAUSED" : "UNPAUSED"; k.ttlMs = 1500; showMessage(k, ms);
    return ev;
  }
  switch (scene_) {
    case SceneId::Pet:
      if (in.button == ButtonEvent::AClick) go(SceneId::Menu, ms);
      else if (in.button == ButtonEvent::BClick) go(SceneId::NameTag, ms);
      else if (in.button == ButtonEvent::BHold) go(SceneId::Status, ms);
      if (in.tap && m_.hitTest(in.tapX, in.tapY)) {
        m_.poke(in.tapX, in.tapY);
        if (s.life == pet::Life::Returning || s.trust < 30) m_.setLook(in.tapX < 233 ? 1.0f : -1.0f, 0);   // turns away
      }
      if (in.stroke) { ev |= care(pet::Care::Stroke); happyUntil_ = ms + 3000; M5.Power.setVibration(90); delay(40); M5.Power.setVibration(0); }
      if (in.shake) { ev |= care(pet::Care::Shake); dizzyUntil_ = ms + 2000; }
      break;
    case SceneId::Menu:
      if (in.button == ButtonEvent::AClick) { sel_ = (MenuItem)(((int)sel_ + 1) % (int)MenuItem::Count); full_ = true; enteredMs_ = ms; }
      else if (in.button == ButtonEvent::BClick) {
        switch (sel_) {
          case MenuItem::Feed:   ev |= care(pet::Care::Meal); break;
          case MenuItem::Snack:  ev |= care(pet::Care::Snack); break;
          case MenuItem::Clean:  ev |= care(pet::Care::Clean); break;
          case MenuItem::Meds:   ev |= care(pet::Care::Medicine); break;
          case MenuItem::Lights: ev |= care(pet::Care::Lights); break;
          case MenuItem::Play:
            if (s.asleep || s.life == pet::Life::Returning) { display::Content k; k.title = "HMPH."; k.ttlMs = 1500; showMessage(k, ms); }
            else { play_.start(ms); go(SceneId::Play, ms); }
            return ev;
          default: break;
        }
        m_.hop(1);
        go(SceneId::Pet, ms);
      } else if (ms - enteredMs_ > 5000) go(SceneId::Pet, ms);
      break;
    case SceneId::Status: case SceneId::NameTag:
      if (in.button == ButtonEvent::BClick || in.button == ButtonEvent::AClick) go(SceneId::Pet, ms);
      else if (scene_ == SceneId::Status && ms - enteredMs_ > 8000) go(SceneId::Pet, ms);
      break;
    case SceneId::Message:
      if (in.button == ButtonEvent::BClick || (msg_.ttlMs && ms - enteredMs_ > msg_.ttlMs))
        go(s.life == pet::Life::Gone ? SceneId::Gone : SceneId::Pet, ms);
      break;
    case SceneId::Gone:
      if (in.button == ButtonEvent::AHold && pet::callBack(s, now)) {
        display::Content k; k.title = "...HI"; k.body = "win me back"; k.ttlMs = 2500; showMessage(k, ms);
      }
      break;
    case SceneId::Play:
      play_.update(in.tiltX, ms);
      if (play_.done(ms)) {
        ev |= care(play_.won() ? pet::Care::PlayWin : pet::Care::PlayLose);
        display::Content k; k.title = play_.won() ? "YOU WIN" : "NICE TRY"; k.ttlMs = 1500; showMessage(k, ms);
      }
      break;
  }
  return ev;
}
```

```cpp
#include "Store.h"
#include "../pet/SaveCodec.h"
#include "../pet/Clock.h"
#include <M5Unified.h>
#include <Preferences.h>
#include <string.h>
namespace store {
static Preferences prefs;
void Store::begin() { prefs.begin("pet", false); }   // NVS namespace "pet"; never touches the ffat partition
bool Store::load(pet::PetState& out) {
  uint8_t buf[pet::SAVE_SIZE];
  const size_t n = prefs.getBytes("state", buf, sizeof buf);
  return pet::decodeSave(buf, n, out);
}
bool Store::save(const pet::PetState& s) {
  uint8_t buf[pet::SAVE_SIZE];
  const size_t n = pet::encodeSave(s, buf, sizeof buf);
  return n && prefs.putBytes("state", buf, n) == n;
}
int64_t Store::nowMin() {
  m5::rtc_datetime_t dt;
  if (!M5.Rtc.getDateTime(&dt) || !pet::plausibleYear(dt.date.year)) return -1;
  return pet::localMinutes(dt.date.year, dt.date.month, dt.date.date, dt.time.hours, dt.time.minutes);
}
void Store::setClock(int y, int mo, int d, int h, int mi) {
  m5::rtc_datetime_t dt;
  dt.date.year = (int16_t)y; dt.date.month = (int8_t)mo; dt.date.date = (int8_t)d;
  dt.time.hours = (int8_t)h; dt.time.minutes = (int8_t)mi; dt.time.seconds = 0;
  M5.Rtc.setDateTime(dt);
}
void Store::ensureClock() {
  if (nowMin() >= 0) return;
  static const char* months = "JanFebMarAprMayJunJulAugSepOctNovDec";
  char mon[4] = {0}; int d = 1, y = 2026, h = 0, mi = 0, sec = 0;
  sscanf(__DATE__, "%3s %d %d", mon, &d, &y);
  sscanf(__TIME__, "%d:%d:%d", &h, &mi, &sec);
  const char* p = strstr(months, mon);
  setClock(y, p ? (int)(p - months) / 3 + 1 : 1, d, h, mi);
}
```

```cpp
static input::Input in;
static store::Store st;
static pet::PetState pet_;

static int64_t debugOffsetMin_ = 0;   // added by the F serial command so every time-gated rule can be tested
static int64_t now() {
  static int64_t cached = -1; static uint32_t readMs = 0;
  if (cached < 0 || millis() - readMs >= 1000) { cached = st.nowMin(); readMs = millis(); }   // RTC is I2C: read at most once a second
  return (cached >= 0 ? cached : pet_.lastMin - debugOffsetMin_) + debugOffsetMin_;

void App::setup() {
  auto cfg = M5.config();
  M5.begin(cfg);
  Serial.begin(115200);
  M5.Display.fillScreen(TFT_BLACK);
  canvas.setPsram(true); canvas.setColorDepth(16); canvas.createSprite(render::SCREEN, render::SCREEN);
  st.begin();
  st.ensureClock();
  const int64_t t = now();
  if (!st.load(pet_)) { pet_ = pet::newPet(t); Serial.println("new pet"); }
  const uint32_t ev = pet::catchUp(pet_, t);
  ui.onEvents(ev, pet_, millis());

  st.save(pet_);
  lastSaveMs_ = millis();
}

void App::serialCommands() {
  if (!Serial.available()) return;
  char line[48] = {0};
  const size_t n = Serial.readBytesUntil('\n', line, sizeof line - 1); line[n] = 0;
  int y, mo, d, h, mi, mins;
  if (sscanf(line, "T %d-%d-%d %d:%d", &y, &mo, &d, &h, &mi) == 5) { st.setClock(y, mo, d, h, mi); Serial.println("clock set"); }
  else if (sscanf(line, "F %d", &mins) == 1) { debugOffsetMin_ += mins; ui.onEvents(pet::catchUp(pet_, now()), pet_, millis()); Serial.println("forwarded"); }
  else if (strncmp(line, "R YES", 5) == 0) { pet_ = pet::newPet(now()); st.save(pet_); Serial.println("new pet"); }
  else if (line[0] == 'S') {
    Serial.printf("min=%lld food=%.0f energy=%.0f joy=%.0f hyg=%.0f trust=%.0f disc=%.0f spoil=%.0f sick=%u messes=%u life=%u asleep=%d paused=%d budget=%.0f age=%u growth=%u mood=%u\n",
      (long long)pet_.lastMin, pet_.food, pet_.energy, pet_.joy, pet_.hygiene, pet_.trust, pet_.discipline, pet_.spoil,
      pet_.sick, pet_.messes, (unsigned)pet_.life, pet_.asleep, pet_.paused, pet_.pauseBudget, (unsigned)pet_.ageMin, pet_.growth,
      (unsigned)pet::moodOf(pet_));
  }
}

  M5.update();
  const uint32_t ms = millis();
  serialCommands();

  const input::InputFrame f = in.poll(ms);
  ev |= ui.handle(f, pet_, now(), ms);
  if (ev) ui.onEvents(ev, pet_, ms);
  if (ev || ui.cared) { st.save(pet_); lastSaveMs_ = ms; ui.cared = false; }

    M5.Display.startWrite();
    M5.Display.setClipRect(push.x, push.y, push.w, push.h);
    canvas.pushSprite(0, 0);
    M5.Display.clearClipRect();
    M5.Display.endWrite();
  }
}
```

```cpp
namespace power {
```

```cpp
}
void PowerMgr::buzz(int pulses) {
  for (int i = 0; i < pulses; i++) { M5.Power.setVibration(200); delay(120); M5.Power.setVibration(0); delay(120); }
}
void PowerMgr::sleepNow(uint32_t seconds) {
  const uint64_t mask = (1ULL << GPIO_NUM_1) | (1ULL << GPIO_NUM_2);   // buttons B and A, active low
  rtc_gpio_pullup_en(GPIO_NUM_1); rtc_gpio_pulldown_dis(GPIO_NUM_1);
  rtc_gpio_pullup_en(GPIO_NUM_2); rtc_gpio_pulldown_dis(GPIO_NUM_2);
#if ESP_IDF_VERSION >= ESP_IDF_VERSION_VAL(5, 3, 0)
  esp_sleep_enable_ext1_wakeup_io(mask, ESP_EXT1_WAKEUP_ANY_LOW);
#else
  esp_sleep_enable_ext1_wakeup(mask, ESP_EXT1_WAKEUP_ANY_LOW);
#endif
  M5.Power.deepSleep((uint64_t)seconds * 1000000ULL, false);
  for (;;) delay(1000);   // deepSleep does not return; guard in case it refuses
}
}
```
