# Phase 2 Talk-to-the-Pet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hold A on the badge, speak, release, and the Charming pet answers out loud in character. You can also text it from a private Charming app. Voice and text share one memory and one personality, and that personality follows the pet's real state.

**Architecture:**
- **The brain** is a Cloudflare Worker with one Durable Object.
  - A pure `PetBrain` class holds all the behavior (tested in Node with injected dependencies). A thin Durable Object wrapper connects it to the runtime.
  - It relays push-to-talk audio between the badge and OpenAI Realtime (`gpt-realtime-2.1-mini`), which is the voice.
  - The realtime model's `think` tool calls Claude Sonnet 5.5, which is the mind.
  - Memory, chat history, the pet snapshot, saved Wi-Fi networks, spend and the device token hash live in the Durable Object's SQLite database.
- **On the badge,** a network task on core 0 owns Wi-Fi, the secure WebSocket and the audio. It exchanges messages with the render loop on core 1 through queues, so networking never stutters the animation.
- **A private Charming app** (on your Pro plan) is the text chat and settings screen. It calls the Worker through `env.fetch` using a shared secret, and receives live updates through a webhook.

**Tech Stack:**
- Brain: TypeScript, Cloudflare Workers + Durable Objects (SQLite), `wrangler`, `@anthropic-ai/sdk`, Vitest on Node 22.5+ (using `node:sqlite` as a stand-in for the Durable Object database).
- Badge: ESP32 Arduino with `WebSockets` (links2004) and `ArduinoJson` 7, plus M5Unified's `Mic` and `Speaker`.
- App: the Charming app contract (`2026-07-31` manifest).

**Spec:** `docs/superpowers/specs/2026-10-12-phase2-talk-design.md` (Phase 1 spec: `docs/superpowers/specs/2026-10-12-phase1-pet-design.md`).

## Global Constraints

- **Models:**
  - The voice model is `gpt-realtime-2.1-mini`, read from configuration as `REALTIME_MODEL`.
  - The mind is `claude-sonnet-5-5`, chosen in the approved spec, read from configuration as `CLAUDE_MODEL`.
  - Claude calls use `client.beta.messages.create` with `betas: ["server-side-fallback-2026-07-01"]`, `fallbacks: "default"`, `output_config: { effort: "low" }`, and an 8 s timeout.
  - `stop_reason` is checked before the content is read.
- **Audio:** 16-bit little-endian PCM, mono, **24 kHz** both ways. The badge records at 24 kHz, so nothing is resampled.
- **Push-to-talk:**
  - `TalkStart` fires after A has been held for **400 ms** with B up.
  - A quick click of A still opens the menu.
  - Pressing B while talking cancels the talk.
  - A turn is sent automatically at **30 s**.
  - Talking is disabled on the Gone screen, where holding A still calls the pet back.
- **Cost:** the default daily cap is **$2** (UTC day). Over the cap, voice gets a fixed "too sleepy" reply and text gets `over_budget`.
- **Secrets:**
  - API keys live only in Worker secrets.
  - The badge holds only its own device token, which can be revoked.
  - The app holds only the shared secret, as the Charming secret `PET_SECRET`.
  - No secret is ever printed in chat or committed.
- **Badge rules stay on the badge:** the AI never changes the pet's stats.
- **Phase 1 constraints still apply:** the partition scheme `app3M_fat9M_16MB`, and no access to `ffat`.
- **Fonts in the chat app:** Silkscreen is embedded as a data URL. Body and label text use the system sans-serif and monospace fonts, because Charming's browser security policy blocks remote font origins.
- **No emdashes** in any copy, and no Claude attribution or session URLs in commits.

## Deviations from the spec (decided while planning)

- **No `DEVICE_TOKEN_HASH` Worker secret.** The brain mints the device token (`/device-token/rotate`) and keeps its SHA-256 in Durable Object storage, so the token never has to be handled by hand. Rotation still closes the old socket immediately.
- **No `OWNER_ID` check in the Worker.** The Charming app is private, so only the owner can run its operations, and the shared secret proves the call came from the app.
- **Fixed 5 s reconnect, not exponential backoff.** This is the WebSockets library's built-in reconnect, with a 20 s heartbeat ping. Backoff can be added later if the badge drains battery while it can't reach the brain.
- **Fonts in the chat app:** Silkscreen is embedded; Inter and Geist Mono fall back to the system sans-serif and monospace fonts. Charming's browser security policy blocks remote font origins.
- **Wi-Fi passwords with spaces** can't be entered over serial (`W ssid password`). Add networks like that from the chat app instead.

## Review Focus

1. **Wi-Fi drops mid-reply.** The badge stops the audio, returns to the mood face, and reconnects. The brain must cancel the realtime response rather than keep billing for it. Covered by a Task 5 test (`talk_cancel` on socket close).
2. **Talking while it is still replying (barge-in).** `talk_start` must cancel the in-progress response before the new turn begins. Covered by a Task 4 test.
3. **The `think` call to Claude hangs or errors.** The realtime model must still get a function output within 8 s so it can answer in character, and the badge must not stay on the thinking face. Covered by a Task 4 test.
4. **A second badge connection, or a token rotated while a connection is open.** The old socket closes, and the stale token is refused on its next connect. Covered by a Task 5 test.
5. **A message from the badge with unexpected JSON** (missing fields, too long, an unknown type). The firmware parser must reject it without overflowing a buffer. Covered by a Task 8 test with oversized and malformed input.

```ts
import { DatabaseSync } from "node:sqlite";
import type { SqlLike } from "../src/store";

// Stand-in for the Durable Object's ctx.storage.sql with the same exec(...).toArray() shape.
export function memSql(): SqlLike {
  const db = new DatabaseSync(":memory:");
  return {
    exec(q: string, ...b: unknown[]) {
      const st = db.prepare(q);
      if (/^\s*(select|with)\b/i.test(q) || /\breturning\b/i.test(q)) {
        const rows = st.all(...(b as never[])) as Record<string, unknown>[];
        return { toArray: () => rows };
      }
      st.run(...(b as never[]));
      return { toArray: () => [] };
    },
  };
}
```

```ts
import { DEFAULT_SETTINGS, type Message, type NetworkEntry, type Settings, type Snapshot } from "./types";

export interface SqlLike { exec(query: string, ...bindings: unknown[]): { toArray(): Record<string, unknown>[] } }

export class PetStore {
  constructor(private sql: SqlLike) {
    // One statement per exec so the same code runs on DO SQL and node:sqlite.
    sql.exec("CREATE TABLE IF NOT EXISTS messages (id INTEGER PRIMARY KEY AUTOINCREMENT, ts INTEGER, channel TEXT, role TEXT, text TEXT)");
    sql.exec("CREATE TABLE IF NOT EXISTS memories (id INTEGER PRIMARY KEY AUTOINCREMENT, ts INTEGER, fact TEXT)");
    sql.exec("CREATE TABLE IF NOT EXISTS networks (ssid TEXT PRIMARY KEY, psk TEXT, ts INTEGER)");
    sql.exec("CREATE TABLE IF NOT EXISTS spend (day TEXT PRIMARY KEY, usd REAL)");
    sql.exec("CREATE TABLE IF NOT EXISTS kv (k TEXT PRIMARY KEY, v TEXT)");
  }
  private kvGet(k: string): string | null {
    const r = this.sql.exec("SELECT v FROM kv WHERE k = ?", k).toArray();
    return r.length ? String(r[0].v) : null;
  }
  private kvSet(k: string, v: string) { this.sql.exec("INSERT INTO kv (k, v) VALUES (?, ?) ON CONFLICT(k) DO UPDATE SET v = excluded.v", k, v); }

  addMessage(channel: Message["channel"], role: Message["role"], text: string, ts: number): Message {
    const r = this.sql.exec("INSERT INTO messages (ts, channel, role, text) VALUES (?, ?, ?, ?) RETURNING id", ts, channel, role, text).toArray();
    return { id: Number(r[0].id), ts, channel, role, text };
  }
  private rowToMsg = (r: Record<string, unknown>): Message => ({ id: Number(r.id), ts: Number(r.ts), channel: r.channel as Message["channel"], role: r.role as Message["role"], text: String(r.text) });
  recentMessages(n: number): Message[] {
    return this.sql.exec("SELECT * FROM messages ORDER BY id DESC LIMIT ?", n).toArray().map(this.rowToMsg).reverse();
  }
  countMessages(): number { return Number(this.sql.exec("SELECT COUNT(*) AS c FROM messages").toArray()[0].c); }
  oldestMessages(n: number): Message[] { return this.sql.exec("SELECT * FROM messages ORDER BY id ASC LIMIT ?", n).toArray().map(this.rowToMsg); }
  deleteMessagesThrough(id: number) { this.sql.exec("DELETE FROM messages WHERE id <= ?", id); }

  addMemory(fact: string, ts: number) { this.sql.exec("INSERT INTO memories (ts, fact) VALUES (?, ?)", ts, fact); }
  memories(): string[] { return this.sql.exec("SELECT fact FROM memories ORDER BY id ASC").toArray().map((r) => String(r.fact)); }

  snapshot(): { snapshot: Snapshot; ts: number } | null {
    const v = this.kvGet("snapshot");
    return v ? (JSON.parse(v) as { snapshot: Snapshot; ts: number }) : null;
  }
  setSnapshot(snapshot: Snapshot, ts: number) { this.kvSet("snapshot", JSON.stringify({ snapshot, ts })); }

  settings(): Settings { const v = this.kvGet("settings"); return { ...DEFAULT_SETTINGS, ...(v ? JSON.parse(v) : {}) }; }
  setSettings(patch: Partial<Settings>) { this.kvSet("settings", JSON.stringify({ ...this.settings(), ...patch })); }

  networks(): NetworkEntry[] { return this.sql.exec("SELECT ssid, psk FROM networks ORDER BY ts ASC").toArray().map((r) => ({ ssid: String(r.ssid), psk: String(r.psk) })); }
  setNetworks(list: NetworkEntry[]) {
    this.sql.exec("DELETE FROM networks");
    list.slice(0, 5).forEach((n, i) => this.sql.exec("INSERT INTO networks (ssid, psk, ts) VALUES (?, ?, ?)", n.ssid, n.psk, i));
  }

  spend(day: string): number { const r = this.sql.exec("SELECT usd FROM spend WHERE day = ?", day).toArray(); return r.length ? Number(r[0].usd) : 0; }
  addSpend(day: string, usd: number) { this.sql.exec("INSERT INTO spend (day, usd) VALUES (?, ?) ON CONFLICT(day) DO UPDATE SET usd = usd + excluded.usd", day, usd); }

  tokenHash(): string | null { return this.kvGet("tokenHash"); }
  setTokenHash(h: string) { this.kvSet("tokenHash", h); }
}
```

```ts
import type { Settings, Snapshot } from "./types";

export function buildSystemPrompt(s: Snapshot | null, settings: Settings, memories: string[], hour: number, channel: "voice" | "text"): string {
  const lines: string[] = [
    `You are ${settings.name}, a small hand-drawn coral flame who lives on Avi's badge. You are a Tamagotchi-style pet with real feelings that come from how Avi treats you.`,
    "You never invent changes to your own stats; you only feel them.",
  ];
  const state: string[] = [];
  if (!s) state.push("You haven't felt your body in a while, so you are unsure how you feel.");
  else {
    if (s.life === "gone") state.push("You ran away and are not here.");
    if (s.life === "returning") state.push("You just came back after running away and don't fully trust Avi yet.");
    if (s.asleep) state.push("You are asleep and were woken up to talk, so you are drowsy.");
    if (s.sick) state.push(`You are sick (stage ${s.sick} of 3) and feel weak.`);
    if (s.food < 25) state.push("You are hungry.");
    if (s.energy < 20) state.push("You are very tired.");
    if (s.hygiene < 25) state.push("You feel dirty.");
    if (s.trust < 30 || s.life === "returning") state.push("Be guarded: short answers, a little wary, warm up only slowly.");
    else if (s.joy > 70) state.push("You are happy: be playful and bright.");
```

```ts
export type CreateMessage = (params: Record<string, unknown>) => Promise<ClaudeReply>;

export function makeCreateMessage(apiKey: string): CreateMessage {
  const client = new Anthropic({ apiKey, maxRetries: 0 });
  // `fallbacks` and `betas` ride on the beta surface; cast because the request is assembled generically.
  return async (params) => (await client.beta.messages.create(params as never, { timeout: 8000 })) as unknown as ClaudeReply;

  {
    name: "remember",
    description: "Save one short fact about Avi or your shared life that you want to remember in future conversations.",
    input_schema: { type: "object", properties: { fact: { type: "string" } }, required: ["fact"], additionalProperties: false },
    strict: true,

    description: "Show something on the badge screen (and in Avi's chat): a short title, an optional one-line body, and optionally a URL to show as a QR code. Use for links, numbers, or anything better seen than heard.",
    input_schema: {
      type: "object",
      properties: { title: { type: "string", maxLength: 23 }, body: { type: "string", maxLength: 63 }, qr: { type: "string", maxLength: 120 } },
      required: ["title"], additionalProperties: false,
    },
    strict: true,
  },
];

export interface MindDeps { create: CreateMessage; model: string; remember(fact: string): void; showCard(card: Card): void }

function toParams(history: Message[]): Array<{ role: "user" | "assistant"; content: string }> {
  // Merge consecutive same-role turns; the API needs alternating roles starting with the user.
  const out: Array<{ role: "user" | "assistant"; content: string }> = [];
  for (const m of history) {
    const role = m.role === "user" ? "user" : "assistant";
    const tag = m.channel === "voice" ? "(said aloud) " : "";
    if (out.length && out[out.length - 1].role === role) out[out.length - 1].content += `\n${tag}${m.text}`;
    else out.push({ role, content: `${tag}${m.text}` });
  }
  while (out.length && out[0].role !== "user") out.shift();
  return out;
}

export async function think(deps: MindDeps, req: { system: string; history: Message[]; question: string }): Promise<{ text: string; usd: number }> {
  const messages: Array<{ role: "user" | "assistant"; content: unknown }> = [...toParams(req.history), { role: "user", content: req.question }];
  // If history ended on a user turn, fold the question into it to keep roles alternating.
  if (messages.length >= 2 && messages[messages.length - 2].role === "user") {
    const q = messages.pop()!; (messages[messages.length - 1] as { content: string }).content += `\n${q.content as string}`;
  }
  let usd = 0;
  try {
    for (let round = 0; round < 3; round++) {
      const r = await deps.create({
        model: deps.model, max_tokens: 2000, system: req.system, messages, tools: MIND_TOOLS,
        betas: ["server-side-fallback-2026-07-01"], fallbacks: "default", output_config: { effort: "low" },
      });
      usd += claudeCost(deps.model, r.usage);
      if (r.stop_reason === "refusal") return { text: "I'd rather not talk about that.", usd };
      if (r.stop_reason !== "tool_use") {
        const text = r.content.filter((b) => b.type === "text").map((b) => String(b.text)).join(" ").trim();
        return { text: text || "Hmm.", usd };
      }
      messages.push({ role: "assistant", content: r.content });
      const results = r.content.filter((b) => b.type === "tool_use").map((b) => {
        const input = b.input as Record<string, string>;
        if (b.name === "remember") deps.remember(String(input.fact).slice(0, 200));
        else if (b.name === "show_card") deps.showCard({ title: String(input.title).slice(0, 23), ...(input.body ? { body: String(input.body).slice(0, 63) } : {}), ...(input.qr ? { qr: String(input.qr).slice(0, 120) } : {}) });
        return { type: "tool_result", tool_use_id: b.id, content: "done" };
      });
      messages.push({ role: "user", content: results });
    }
  } catch {
    return { text: "I couldn't think of it just now.", usd };
  }
  return { text: "I couldn't think of it just now.", usd };
}
```

```ts
import type { Face } from "./types";

export interface WsLike { send(d: string | ArrayBuffer): void; close(code?: number): void; addEventListener(type: "message" | "close" | "error", fn: (e: { data?: unknown }) => void): void }
export interface RealtimeEvents {
  audio(pcm: ArrayBuffer): void; face(f: Face): void; done(): void;
  userTranscript(t: string): void; petTranscript(t: string): void; usage(u: RealtimeUsage): void;
  think(question: string): Promise<string>; error(code: "brain_fog"): void;
}
interface Timers { set: (fn: () => void, ms: number) => unknown; clear: (h: unknown) => void }

const toB64 = (buf: ArrayBuffer) => { let s = ""; const u = new Uint8Array(buf); for (let i = 0; i < u.length; i++) s += String.fromCharCode(u[i]); return btoa(s); };
const fromB64 = (b64: string) => { const s = atob(b64); const u = new Uint8Array(s.length); for (let i = 0; i < s.length; i++) u[i] = s.charCodeAt(i); return u.buffer; };

export class RealtimeLink {
  private ws: WsLike | null = null;
  private opening: Promise<void> | null = null;
  private responding = false;
  private spoke = false;
  private fogTimer: unknown = null;
  private pending: ArrayBuffer[] = [];   // audio that arrived before the upstream socket opened
  constructor(
    private open: () => Promise<WsLike>,
    private cfg: { model: string; voice: string; instructions: string; transcribeModel: string },
    private ev: RealtimeEvents,
    private timers: Timers = { set: (f, ms) => setTimeout(f, ms), clear: (h) => clearTimeout(h as number) },
  ) {}
  get isOpen() { return this.ws !== null; }

  ensure(): Promise<void> {
    if (this.ws) return Promise.resolve();
    this.opening ??= this.open().then((ws) => {
      this.ws = ws;
      ws.addEventListener("message", (e) => this.onMessage(String(e.data)));
      ws.addEventListener("close", () => { this.ws = null; this.opening = null; this.responding = false; });
      ws.addEventListener("error", () => this.ev.error("brain_fog"));
      this.send({
        type: "session.update",
        session: {
          type: "realtime", model: this.cfg.model, output_modalities: ["audio"], instructions: this.cfg.instructions,
          audio: {
            input: { format: { type: "audio/pcm", rate: 24000 }, turn_detection: null, transcription: { model: this.cfg.transcribeModel } },
            output: { format: { type: "audio/pcm", rate: 24000 }, voice: this.cfg.voice },
          },
          tools: [{
            type: "function", name: "think",
            description: "Ask your deeper mind about anything that needs memory, facts, planning, or showing something on the badge screen. Say a very short in-character filler line first.",
            parameters: { type: "object", properties: { question: { type: "string" } }, required: ["question"] },
          }],
          tool_choice: "auto",
        },
      });
    });
    return this.opening;
  }

  startTurn() {
    if (this.responding) { this.send({ type: "response.cancel" }); this.responding = false; }
    this.clearFog();
    this.send({ type: "input_audio_buffer.clear" });
    // Flush audio queued while the socket was opening; after the clear, or the clear would wipe it.
    for (const b of this.pending.splice(0)) this.send({ type: "input_audio_buffer.append", audio: toB64(b) });
  }
  appendAudio(buf: ArrayBuffer) {
    if (!this.ws) { if (this.pending.length < 50) this.pending.push(buf); return; }   // ~2 s cap
    this.send({ type: "input_audio_buffer.append", audio: toB64(buf) });
  }
  endTurn() {
    this.send({ type: "input_audio_buffer.commit" });
    this.createResponse();
  }
  cancelTurn() {
    this.pending = [];
    this.send({ type: "input_audio_buffer.clear" });
    if (this.responding) { this.send({ type: "response.cancel" }); this.responding = false; }
    this.clearFog();
  }
  setInstructions(text: string) { this.cfg.instructions = text; if (this.ws) this.send({ type: "session.update", session: { type: "realtime", instructions: text } }); }
  close() { this.clearFog(); this.ws?.close(1000); this.ws = null; this.opening = null; }

  private createResponse() {
    this.responding = true; this.spoke = false;
    this.send({ type: "response.create" });
    this.clearFog();
    this.fogTimer = this.timers.set(() => { if (!this.spoke) { this.cancelTurn(); this.ev.error("brain_fog"); } }, 10_000);
  }
  private clearFog() { if (this.fogTimer !== null) { this.timers.clear(this.fogTimer); this.fogTimer = null; } }
  private send(obj: unknown) { this.ws?.send(JSON.stringify(obj)); }

  private onMessage(raw: string) {
    let e: { type?: string; [k: string]: any };
    try { e = JSON.parse(raw); } catch { return; }
    switch (e.type) {
      case "response.output_audio.delta":
        if (!this.spoke) { this.spoke = true; this.clearFog(); this.ev.face("speaking"); }
        this.ev.audio(fromB64(String(e.delta)));
        break;
      case "response.output_audio_transcript.done": this.ev.petTranscript(String(e.transcript ?? "")); break;
      case "conversation.item.input_audio_transcription.completed": this.ev.userTranscript(String(e.transcript ?? "")); break;
      case "error": this.ev.error("brain_fog"); break;
      case "response.done": {
        this.responding = false;
        if (e.response?.usage) this.ev.usage(e.response.usage as RealtimeUsage);
        if (e.response?.status === "cancelled") return;   // barge-in: a new turn is already under way
        const call = (e.response?.output ?? []).find((o: any) => o.type === "function_call" && o.name === "think");
        if (call) { void this.runThink(String(call.call_id), String(call.arguments ?? "{}")); return; }
        this.clearFog();
        this.ev.done();
        break;
      }
    }
  }

  private async runThink(callId: string, args: string) {
    this.clearFog();
    this.ev.face("thinking");
    let question = "";
    try { question = String(JSON.parse(args).question ?? ""); } catch { /* empty question */ }
    const timeout = new Promise<string>((res) => this.timers.set(() => res("I couldn't think of it just now."), 8000));
    const answer = await Promise.race([this.ev.think(question).catch(() => "I couldn't think of it just now."), timeout]);
    this.send({ type: "conversation.item.create", item: { type: "function_call_output", call_id: callId, output: answer } });
    this.createResponse();
  }
}
```

```ts
import { think, type CreateMessage } from "./mind";
import { buildSystemPrompt } from "./personality";
import { RealtimeLink, type WsLike } from "./realtime";
import { dayKey, realtimeCost } from "./spend";
import type { PetStore } from "./store";
import type { Card, Message, NetworkEntry, Settings, Snapshot } from "./types";

export interface BrainDeps {
  store: PetStore; now(): number;
  sendBadgeJson(o: unknown): void; sendBadgeAudio(b: ArrayBuffer): void; closeBadge(): void;
  openUpstream(model: string): Promise<WsLike>; createMessage: CreateMessage;
  pushApp(event: { kind: "message"; message: Message } | { kind: "snapshot"; snapshot: Snapshot } | { kind: "card"; card: Card }): void;
  claudeModel: string; transcribeModel: string;
  sha256(s: string): Promise<string>; randomToken(): string;
}

export class PetBrain {
  private link: RealtimeLink | null = null;
  private idle: ReturnType<typeof setTimeout> | null = null;
  private lastCard: Card | undefined;
  constructor(private d: BrainDeps) {}

  // The badge's local hour from its last snapshot; UTC only as a fallback (Workers run in UTC).
  private hourLocal() { return this.d.store.snapshot()?.snapshot.hour ?? new Date(this.d.now()).getUTCHours(); }
  private prompt(channel: "voice" | "text") {
    return buildSystemPrompt(this.d.store.snapshot()?.snapshot ?? null, this.d.store.settings(), this.d.store.memories(), this.hourLocal(), channel);
  }
  private overBudget() { return this.d.store.spend(dayKey(this.d.now())) >= this.d.store.settings().dailyCapUsd; }
  private addSpend(usd: number) { if (usd > 0) this.d.store.addSpend(dayKey(this.d.now()), usd); }
  private message(channel: Message["channel"], role: Message["role"], text: string) {
    if (!text.trim()) return;
    const m = this.d.store.addMessage(channel, role, text.trim(), this.d.now());
    if (channel === "voice") this.d.pushApp({ kind: "message", message: m });
  }
  private card = (c: Card) => { this.lastCard = c; this.d.sendBadgeJson({ t: "card", ...c }); this.d.pushApp({ kind: "card", card: c }); };
  private async mind(channel: "voice" | "text", question: string) {
    const r = await think({ create: this.d.createMessage, model: this.d.claudeModel, remember: (f) => this.d.store.addMemory(f, this.d.now()), showCard: this.card },
      { system: this.prompt(channel), history: this.d.store.recentMessages(30), question });
    this.addSpend(r.usd);
    return r.text;
  }

  private ensureLink(): RealtimeLink {
    if (this.link) return this.link;
    const settings: Settings = this.d.store.settings();
    this.link = new RealtimeLink(() => this.d.openUpstream(settings.realtimeModel),
      { model: settings.realtimeModel, voice: settings.voice, instructions: this.prompt("voice"), transcribeModel: this.d.transcribeModel },
      {
        audio: (b) => this.d.sendBadgeAudio(b),
        face: (f) => this.d.sendBadgeJson({ t: "face", f }),
        done: () => { this.d.sendBadgeJson({ t: "say_end" }); this.armIdle(); },
        userTranscript: (t) => this.message("voice", "user", t),
        petTranscript: (t) => this.message("voice", "pet", t),
        usage: (u) => this.addSpend(realtimeCost(settings.realtimeModel, u)),
        think: (q) => this.mind("voice", q),
        error: (code) => { this.d.sendBadgeJson({ t: "error", code }); this.armIdle(); },
      });
    return this.link;
  }
  private armIdle() {
    if (this.idle) clearTimeout(this.idle);
    this.idle = setTimeout(() => { this.link?.close(); this.link = null; }, 30_000);
  }

  // ---- badge socket ----
  // Networks are pushed only after hello merges the badge's own list, so the badge never gets an
  // empty list on its first connection and forgets its Wi-Fi.
  onBadgeOpen() {}
  async onBadgeJson(text: string) {
    let m: { t?: string; snapshot?: Snapshot; [k: string]: unknown };
    try { m = JSON.parse(text); } catch { return; }
    switch (m.t) {
      case "hello":
        if (m.snapshot) this.setSnapshot(m.snapshot);
        if (Array.isArray(m.networks)) this.setNetworks(m.networks as NetworkEntry[]);
        else this.d.sendBadgeJson({ t: "networks", list: this.d.store.networks() });
        break;
      case "add_network": if (typeof m.ssid === "string") this.setNetworks([{ ssid: m.ssid, psk: String(m.psk ?? "") }]); break;
      case "snapshot": { const { t: _t, ...s } = m; this.setSnapshot(s as unknown as Snapshot); break; }
      case "talk_start": {
        if (this.idle) clearTimeout(this.idle);
        if (this.overBudget()) { this.d.sendBadgeJson({ t: "error", code: "over_budget" }); return; }
        const link = this.ensureLink();
        this.d.sendBadgeJson({ t: "face", f: "listening" });
        try { await link.ensure(); } catch { this.d.sendBadgeJson({ t: "error", code: "brain_fog" }); return; }
        link.startTurn();
        break;
      }
      case "talk_end": this.link?.endTurn(); break;
      case "talk_cancel": this.link?.cancelTurn(); this.d.sendBadgeJson({ t: "face", f: "idle" }); this.armIdle(); break;
      default: return;
    }
  }
  onBadgeAudio(buf: ArrayBuffer) { this.link?.appendAudio(buf); }
  onBadgeClose() { this.link?.cancelTurn(); this.armIdle(); }
  private setSnapshot(s: Snapshot) {
    this.d.store.setSnapshot(s, this.d.now());
    this.d.pushApp({ kind: "snapshot", snapshot: s });
    this.link?.setInstructions(this.prompt("voice"));
  }

  // ---- app routes ----
  async chat(text: string): Promise<{ reply: string; card?: Card } | { error: string }> {
    if (this.overBudget()) return { error: "over_budget" };
    this.lastCard = undefined;
    const history = this.d.store.recentMessages(30);
    this.d.store.addMessage("text", "user", text, this.d.now());
    const r = await think({ create: this.d.createMessage, model: this.d.claudeModel, remember: (f) => this.d.store.addMemory(f, this.d.now()), showCard: this.card },
      { system: this.prompt("text"), history, question: text });
    this.addSpend(r.usd);
    this.d.store.addMessage("text", "pet", r.text, this.d.now());
    return this.lastCard ? { reply: r.text, card: this.lastCard } : { reply: r.text };
  }
  state() {
    const s = this.d.store.snapshot();
    return {
      snapshot: s?.snapshot ?? null, snapshotTs: s?.ts ?? null, settings: this.d.store.settings(),
      spendToday: this.d.store.spend(dayKey(this.d.now())),
      networks: this.d.store.networks().map((n) => ({ ssid: n.ssid })),
      messages: this.d.store.recentMessages(100),
    };
  }
  setSettings(patch: Partial<Settings>) { this.d.store.setSettings(patch); if (patch.voice || patch.realtimeModel) { this.link?.close(); this.link = null; } return this.d.store.settings(); }
  // Merge by SSID so adding one network from the app never drops the others; newest wins, max 5.
  setNetworks(list: NetworkEntry[]) {
    const incoming = list.filter((n) => n.ssid).map((n) => n.ssid);
    const kept = this.d.store.networks().filter((n) => !incoming.includes(n.ssid));
    this.d.store.setNetworks([...kept, ...list.filter((n) => n.ssid)].slice(-5));
    this.d.sendBadgeJson({ t: "networks", list: this.d.store.networks() });
    return { ok: true };
  }
  removeNetwork(ssid: string) {
    this.d.store.setNetworks(this.d.store.networks().filter((n) => n.ssid !== ssid));
    this.d.sendBadgeJson({ t: "networks", list: this.d.store.networks() });
    return { ok: true };
  }
  async rotateToken() {
    const token = this.d.randomToken();
    this.d.store.setTokenHash(await this.d.sha256(token));
    this.d.closeBadge();   // the old token's socket goes away immediately
    return { token };
  }
  async checkToken(bearer: string) { const h = this.d.store.tokenHash(); return !!h && h === (await this.d.sha256(bearer)); }
  async compact() {
    if (this.d.store.countMessages() <= 500) return { compacted: 0 };
    const old = this.d.store.oldestMessages(400);
    const r = await think({ create: this.d.createMessage, model: this.d.claudeModel, remember: (f) => this.d.store.addMemory(f, this.d.now()), showCard: () => {} },
      { system: "You condense a pet's chat log into durable memories. Call remember once per important fact about Avi or your shared life (at most 15). Then reply 'done'.", history: [], question: old.map((m) => `${m.role}: ${m.text}`).join("\n") });
    this.addSpend(r.usd);
    this.d.store.deleteMessagesThrough(old[old.length - 1].id);
    return { compacted: old.length };
  }
}
```

```ts
export class Pet extends DurableObject<Env> {
```

```cpp
#include "Protocol.h"
#include <ArduinoJson.h>
#include <string.h>
namespace net {
static void copy(char* dst, size_t cap, const char* src) {
  if (!src) { dst[0] = 0; return; }
  strncpy(dst, src, cap - 1); dst[cap - 1] = 0;
}
bool parse(const char* json, size_t n, Incoming& out) {
  JsonDocument doc;
  if (deserializeJson(doc, json, n) || !doc.is<JsonObject>()) return false;
  const char* t = doc["t"] | "";
  out = Incoming{};
  if (!strcmp(t, "face")) {
    const char* f = doc["f"] | "idle";
    out.kind = Incoming::FaceMsg;
    out.face = !strcmp(f, "listening") ? Face::Listening : !strcmp(f, "thinking") ? Face::Thinking : !strcmp(f, "speaking") ? Face::Speaking : Face::Idle;
    return true;
  }
  if (!strcmp(t, "card")) {
    out.kind = Incoming::CardMsg;
    copy(out.card.title, sizeof out.card.title, doc["title"] | "");
    copy(out.card.body, sizeof out.card.body, doc["body"] | "");
    copy(out.card.qr, sizeof out.card.qr, doc["qr"] | "");
    return true;
  }
  if (!strcmp(t, "say_end")) { out.kind = Incoming::SayEnd; return true; }
  if (!strcmp(t, "error")) {
    const char* c = doc["code"] | "";
    out.kind = Incoming::Error;
    out.err = !strcmp(c, "over_budget") ? Err::OverBudget : !strcmp(c, "brain_fog") ? Err::BrainFog : !strcmp(c, "busy") ? Err::Busy : Err::Other;
    return true;
  }
  if (!strcmp(t, "networks")) {
    out.kind = Incoming::Networks;
    for (JsonObject n : doc["list"].as<JsonArray>()) {
      if (out.netCount >= 5) break;
      copy(out.nets[out.netCount].ssid, sizeof out.nets[0].ssid, n["ssid"] | "");
      copy(out.nets[out.netCount].psk, sizeof out.nets[0].psk, n["psk"] | "");
      if (out.nets[out.netCount].ssid[0]) out.netCount++;
    }
    return true;
  }
  return false;
}
static void fillSnapshot(JsonObject o, const SnapshotWire& s) {
  o["mood"] = s.mood; o["food"] = (int)s.food; o["energy"] = (int)s.energy; o["joy"] = (int)s.joy;
  o["hygiene"] = (int)s.hygiene; o["trust"] = (int)s.trust; o["sick"] = s.sick; o["life"] = s.life;
  o["asleep"] = s.asleep; o["ageDays"] = s.ageDays; o["growth"] = s.growth; o["hour"] = s.hour;
}
static size_t finish(JsonDocument& doc, char* buf, size_t cap) {
  if (measureJson(doc) + 1 > cap) return 0;
  return serializeJson(doc, buf, cap);
}
size_t encodeHello(char* buf, size_t cap, const char* fw, const SnapshotWire& s, const Network* nets, uint8_t netCount) {
  JsonDocument doc; doc["t"] = "hello"; doc["fw"] = fw; fillSnapshot(doc["snapshot"].to<JsonObject>(), s);
  JsonArray list = doc["networks"].to<JsonArray>();
  for (uint8_t i = 0; i < netCount; i++) { JsonObject o = list.add<JsonObject>(); o["ssid"] = nets[i].ssid; o["psk"] = nets[i].psk; }
  return finish(doc, buf, cap);
}
size_t encodeAddNetwork(char* buf, size_t cap, const Network& n) {
  JsonDocument doc; doc["t"] = "add_network"; doc["ssid"] = n.ssid; doc["psk"] = n.psk;
  return finish(doc, buf, cap);
}
size_t encodeSnapshot(char* buf, size_t cap, const SnapshotWire& s) {
  JsonDocument doc; doc["t"] = "snapshot"; fillSnapshot(doc.as<JsonObject>(), s);
  return finish(doc, buf, cap);
}
size_t encodeType(char* buf, size_t cap, const char* t) {
  JsonDocument doc; doc["t"] = t;
  return finish(doc, buf, cap);
}
}
```

```cpp
void WifiManager::begin() {
  prefs.begin("net", false);
  n_ = (uint8_t)(prefs.getBytes("list", list_, sizeof list_) / sizeof(Network));
  if (n_ > 5) n_ = 0;
  while (n_ > 0 && !list_[n_ - 1].ssid[0]) n_--;

void WifiManager::save() { prefs.putBytes("list", list_, sizeof(Network) * n_); }
void WifiManager::add(const char* ssid, const char* psk) {
  for (uint8_t i = 0; i < n_; i++) if (!strcmp(list_[i].ssid, ssid)) { strncpy(list_[i].psk, psk, 64); list_[i].psk[64] = 0; save(); return; }
  if (n_ == 5) { memmove(&list_[0], &list_[1], sizeof(Network) * 4); n_ = 4; }   // drop the oldest
  strncpy(list_[n_].ssid, ssid, 32); list_[n_].ssid[32] = 0;
  strncpy(list_[n_].psk, psk, 64); list_[n_].psk[64] = 0;
  n_++; save();
}
void WifiManager::setAll(const Network* l, uint8_t n) { n_ = n > 5 ? 5 : n; memcpy(list_, l, sizeof(Network) * n_); save(); }
void WifiManager::connect() {
  if (!n_) return;
  WiFi.mode(WIFI_STA); WiFi.setSleep(true);
  WiFi.scanNetworks(true);
  s_ = S::Scanning; t0_ = millis();
}
void WifiManager::poll() {
  if (s_ == S::Scanning) {
    const int16_t found = WiFi.scanComplete();
    if (found == WIFI_SCAN_RUNNING) return;
    int best = -1, bestRssi = -1000;
    for (int i = 0; i < found; i++)
      for (uint8_t k = 0; k < n_; k++)
        if (WiFi.SSID(i) == list_[k].ssid && WiFi.RSSI(i) > bestRssi) { best = k; bestRssi = WiFi.RSSI(i); }
    WiFi.scanDelete();
    if (best < 0) { s_ = S::Idle; t0_ = millis(); return; }   // nothing known in range; retried by the task
    WiFi.begin(list_[best].ssid, list_[best].psk);
    s_ = S::Joining; t0_ = millis();
  } else if (s_ == S::Joining) {
    if (WiFi.status() == WL_CONNECTED) s_ = S::Up;
    else if (millis() - t0_ > 15000) { WiFi.disconnect(); s_ = S::Idle; }
  } else if (s_ == S::Up && WiFi.status() != WL_CONNECTED) {
    s_ = S::Idle;
  } else if (s_ == S::Idle && n_ && millis() - t0_ > 10000) {
    connect();
  }
}
bool WifiManager::connected() const { return s_ == S::Up && WiFi.status() == WL_CONNECTED; }
void WifiManager::off() { WiFi.disconnect(true); WiFi.mode(WIFI_OFF); s_ = S::Idle; }
```

```cpp
#include <stdint.h>
#include <stddef.h>
namespace audio {
constexpr uint32_t RATE = 24000;
constexpr size_t CHUNK = 960;   // 40 ms at 24 kHz
class Voice {
 public:
  void begin();
  void startRecording();
  void stopRecording();

  void enqueuePlayback(const uint8_t* pcm, size_t bytes);

  int16_t* ring_ = nullptr; size_t ringCap_ = 0, head_ = 0, tail_ = 0;   // samples
  int16_t* play_[3] = {nullptr, nullptr, nullptr}; uint8_t playIdx_ = 0;
  bool flushing_ = false; volatile float level_ = 0;
  size_t ringCount() const { return (head_ + ringCap_ - tail_) % ringCap_; }
```

```cpp
#include "Voice.h"
#include <M5Unified.h>
#include <math.h>
#include <string.h>
namespace audio {
void Voice::begin() {
  for (auto& b : rec_) b = (int16_t*)heap_caps_malloc(CHUNK * 2, MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL);
  for (auto& b : play_) b = (int16_t*)heap_caps_malloc(CHUNK * 2, MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL);
  ringCap_ = RATE * 4;   // 4 s of reply audio
  ring_ = (int16_t*)heap_caps_malloc(ringCap_ * 2, MALLOC_CAP_SPIRAM);
  M5.Speaker.setVolume(180);
}
// The mic and speaker share one codec on this board, so only one of them runs at a time.
void Voice::startRecording() {
  stopPlayback(); M5.Speaker.end();
  M5.Mic.begin();
  recording_ = true; recIdx_ = 0; recQueued_ = 0;
}
void Voice::stopRecording() {
  recording_ = false;
  while (M5.Mic.isRecording()) delay(1);
  M5.Mic.end();
  M5.Speaker.begin();
}
bool Voice::recordChunk(const int16_t*& out, size_t& n) {
  if (!recording_) return false;
  // Keep up to two slots queued; the chunk two behind the newest is complete.
  if (recQueued_ < 3 && M5.Mic.isRecording() < 2) {
    M5.Mic.record(rec_[recIdx_ % 3], CHUNK, RATE);
    recIdx_++; recQueued_++;
  }
  if (recQueued_ >= 3) { out = rec_[(recIdx_ - 3) % 3]; n = CHUNK; recQueued_--; return true; }
  return false;
}
void Voice::enqueuePlayback(const uint8_t* pcm, size_t bytes) {
  const int16_t* s = (const int16_t*)pcm; size_t n = bytes / 2;
  for (size_t i = 0; i < n; i++) {
    const size_t next = (head_ + 1) % ringCap_;
    if (next == tail_) break;   // ring full: drop the newest samples
    ring_[head_] = s[i]; head_ = next;
  }
  flushing_ = false;
}
void Voice::pumpPlayback() {
  // Start once 120 ms is buffered (jitter cushion); refill whenever fewer than 2 chunks are queued.
  const size_t want = (M5.Speaker.isPlaying(0) ? CHUNK : CHUNK * 3);
  while (M5.Speaker.isPlaying(0) < 2 && (ringCount() >= want || (flushing_ && ringCount() > 0))) {
    int16_t* buf = play_[playIdx_ % 3];
    const size_t n = ringCount() < CHUNK ? ringCount() : CHUNK;
    double acc = 0;
    for (size_t i = 0; i < n; i++) { buf[i] = ring_[tail_]; tail_ = (tail_ + 1) % ringCap_; acc += (double)buf[i] * buf[i]; }
    level_ = fminf(1.0f, sqrtf((float)(acc / (n ? n : 1))) / 6000.0f);
    M5.Speaker.playRaw(buf, n, RATE, false, 1, 0);
    playIdx_++;
  }
  if (!M5.Speaker.isPlaying(0) && ringCount() == 0) level_ = 0;
}
void Voice::flushPlayback() { flushing_ = true; }
void Voice::stopPlayback() { M5.Speaker.stop(0); head_ = tail_ = 0; level_ = 0; flushing_ = false; }
bool Voice::playing() const { return M5.Speaker.isPlaying(0) || head_ != tail_; }
}
```

```cpp
static void onWs(WStype_t type, uint8_t* payload, size_t len) {
  switch (type) {
    case WStype_CONNECTED: {
      emitStatus(Status::Online);
      char buf[1024]; Network nets[5]; const uint8_t k = wifi.count();
      for (uint8_t i = 0; i < k; i++) nets[i] = wifi.at(i);
      const size_t n = encodeHello(buf, sizeof buf, FW_VERSION, lastSnap, nets, k);
      if (n) ws.sendTXT(buf, n);
      break;
    }
    case WStype_DISCONNECTED:
      if (talking) { voice.stopRecording(); talking = false; }
      voice.stopPlayback();
      emitStatus(len >= 2 && payload && ((payload[0] << 8) | payload[1]) == 4001 ? Status::BadToken : Status::NoBrain);
      break;
    case WStype_TEXT: {
      Event e{Event::In, Status::Online, {}};
      if (!parse((const char*)payload, len, e.in)) break;
      if (e.in.kind == Incoming::Networks && e.in.netCount > 0) wifi.setAll(e.in.nets, e.in.netCount);   // never wipe the list
      if (e.in.kind == Incoming::SayEnd) voice.flushPlayback();
      xQueueSend(evtQ, &e, 0);
      break;
    }
    case WStype_BIN: voice.enqueuePlayback(payload, len); break;
    case WStype_ERROR:
      // The library reports an HTTP 401 on upgrade here; treat it as a bad token
      if (payload && strstr((const char*)payload, "401")) emitStatus(Status::BadToken);
      break;
    default: break;
  }
}
static void startWs() {
  if (wsStarted || !token[0]) return;
  static char hdr[96];
  snprintf(hdr, sizeof hdr, "Authorization: Bearer %s", token);
  ws.beginSSL(BRAIN_HOST, 443, "/badge");
  ws.setExtraHeaders(hdr);
  ws.onEvent(onWs);
  ws.setReconnectInterval(5000);
  ws.enableHeartbeat(20000, 5000, 2);
  wsStarted = true;
}
static void task(void*) {
  Preferences p; p.begin("net", false); p.getString("token", token, sizeof token);
  wifi.begin(); voice.begin();
  emitStatus(wifi.count() ? Status::Connecting : Status::NoWifi);
  wifi.connect();
  for (;;) {
    Cmd c;
    while (xQueueReceive(cmdQ, &c, 0)) {
      switch (c.kind) {
        case Cmd::Snapshot: case Cmd::Hello: {
          lastSnap = c.snap;
          if (ws.isConnected()) {
            char buf[1024]; Network nets[5]; const uint8_t k = wifi.count();
            for (uint8_t i = 0; i < k; i++) nets[i] = wifi.at(i);
            const size_t n = c.kind == Cmd::Hello ? encodeHello(buf, sizeof buf, FW_VERSION, c.snap, nets, k) : encodeSnapshot(buf, sizeof buf, c.snap);
            if (n) ws.sendTXT(buf, n);
          }
          break;
        }
        case Cmd::TalkStart: if (ws.isConnected()) { char b[32]; ws.sendTXT(b, encodeType(b, sizeof b, "talk_start")); voice.startRecording(); talking = true; } break;
        case Cmd::TalkEnd: if (talking) { voice.stopRecording(); talking = false; char b[32]; ws.sendTXT(b, encodeType(b, sizeof b, "talk_end")); } break;
        case Cmd::TalkCancel: if (talking) { voice.stopRecording(); talking = false; } { char b[32]; if (ws.isConnected()) ws.sendTXT(b, encodeType(b, sizeof b, "talk_cancel")); } voice.stopPlayback(); break;
        case Cmd::SetToken: strncpy(token, c.text, 64); token[64] = 0; p.putString("token", token); if (wsStarted) { ws.disconnect(); wsStarted = false; } break;
        case Cmd::AddNetwork: {
          wifi.add(c.text, c.text2);
          if (ws.isConnected()) { Network n{}; strncpy(n.ssid, c.text, 32); strncpy(n.psk, c.text2, 64); char b[160]; const size_t len = encodeAddNetwork(b, sizeof b, n); if (len) ws.sendTXT(b, len); }
          if (!wifi.connected()) wifi.connect();
          break;
        }
        case Cmd::Stop: if (wsStarted) ws.disconnect(); wifi.off(); vTaskDelete(nullptr); break;
      }
    }
    wifi.poll();
    if (wifi.connected()) { startWs(); ws.loop(); if (!ws.isConnected() && stat.load() == (uint8_t)Status::Online) emitStatus(Status::NoBrain); }
    else emitStatus(wifi.count() ? Status::Connecting : Status::NoWifi);
    const int16_t* chunk; size_t n;
    while (talking && voice.recordChunk(chunk, n)) ws.sendBIN((const uint8_t*)chunk, n * 2);
    voice.pumpPlayback();
    level = voice.level();
    vTaskDelay(1);
  }
```

```js
async function brain(env, method, path, body) {
  const res = await env.fetch(BRAIN + path, {
    method,
    headers: { 'Content-Type': 'application/json', 'X-App-Secret': '{{secret:PET_SECRET}}' },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  if (!res.ok) return { error: `brain_${res.status}` };

}
// Writes only when something new was added: every storage write fires onStateChange, and the UI's
// refresh calls `state`, so an unconditional write here would loop the app into app_busy.
async function pushFeed(env, items) {
  const feed = (await env.storage.get('feed')) ?? [];
  let added = 0;
  for (const it of items) if (!feed.some((f) => f.key === it.key)) { feed.push(it); added++; }
  if (added) await env.storage.put('feed', feed.slice(-300));
}
export const routes = [
  {
    op: 'state', method: 'GET', annotations: { readOnlyHint: true },
    handler: async (_i, { env }) => {
      const s = await brain(env, 'GET', '/state');
      if (s.error) return { error: s.error, feed: (await env.storage.get('feed')) ?? [] };
      // Seed from the brain's log once, when the feed is empty; the webhook keeps it current after that.
      if (!((await env.storage.get('feed')) ?? []).length)
        await pushFeed(env, s.messages.map((m) => ({ key: `m${m.id}`, ts: m.ts, kind: 'message', channel: m.channel, role: m.role, text: m.text })));
      return { ...s, messages: undefined, feed: (await env.storage.get('feed')) ?? [] };
    },
  },
  {
    op: 'chat', method: 'POST',
    inputSchema: { type: 'object', required: ['text'], properties: { text: { type: 'string', maxLength: 2000 } }, additionalProperties: false },
    handler: async ({ text }, { env }) => {
      const now = Date.now();
      await pushFeed(env, [{ key: `u${now}`, ts: now, kind: 'message', channel: 'text', role: 'user', text }]);
      const r = await brain(env, 'POST', '/chat', { text });
      if (r.error) return { error: r.error };
      const items = [{ key: `p${now}`, ts: Date.now(), kind: 'message', channel: 'text', role: 'pet', text: r.reply }];
      if (r.card) items.push({ key: `c${now}`, ts: Date.now(), kind: 'card', card: r.card });
      await pushFeed(env, items);
      return r;
    },
  },
  {
    op: 'setSettings', method: 'POST',
    inputSchema: { type: 'object', properties: { name: { type: 'string', maxLength: 20 }, voice: { type: 'string' }, dailyCapUsd: { type: 'number', minimum: 0, maximum: 50 } }, additionalProperties: false },
    handler: async (input, { env }) => brain(env, 'PUT', '/settings', input),
  },
  {
    op: 'setNetworks', method: 'POST',
    inputSchema: { type: 'object', required: ['list'], properties: { list: { type: 'array', maxItems: 5, items: { type: 'object', required: ['ssid', 'psk'], properties: { ssid: { type: 'string', maxLength: 32 }, psk: { type: 'string', maxLength: 64 } }, additionalProperties: false } } }, additionalProperties: false },
    handler: async (input, { env }) => brain(env, 'PUT', '/networks', input),
  },

  { op: 'compact', method: 'POST', handler: async (_i, { env }) => brain(env, 'POST', '/compact', {}) },
  {
    op: 'ingest', method: 'POST',
    inputSchema: { type: 'object', required: ['kind'], properties: { kind: { type: 'string' }, message: { type: 'object' }, snapshot: { type: 'object' }, card: { type: 'object' } } },
    handler: async (e, { env }) => {
      if (e.kind === 'snapshot') { await env.storage.put('snapshot', { snapshot: e.snapshot, ts: Date.now() }); return { ok: true }; }
      if (e.kind === 'message' && e.message) await pushFeed(env, [{ key: `m${e.message.id}`, ts: e.message.ts, kind: 'message', channel: e.message.channel, role: e.message.role, text: e.message.text }]);

      return { ok: true };
    },
  },
];
```

```js
    try { const r = await api.chat({ text }); if (r.error === 'over_budget') alert('Too sleepy to talk today (daily spend cap reached).'); else if (r.error) alert('Could not reach the pet.'); }
    finally { sending = false; await refresh(); }
  };
  return bar;
}
function settingsView(s) {
  const p = el('div', 'cp-set');
  const name = el('input'); name.value = s.settings?.name ?? ''; name.maxLength = 20;
  const cap = el('input'); cap.type = 'number'; cap.step = '0.5'; cap.value = s.settings?.dailyCapUsd ?? 2;
  const l1 = el('label', '', 'Name'); l1.append(name);
  const l2 = el('label', '', `Daily spend cap (today $${(s.spendToday ?? 0).toFixed(2)})`); l2.append(cap);
  const save = el('button', 'cp-btn', 'SAVE'); save.style.padding = '10px';
  save.onclick = async () => { await api.setSettings({ name: name.value.trim() || 'Charm', dailyCapUsd: Number(cap.value) || 0 }); await refresh(); };
  p.append(l1, l2, save);
  const nets = el('label', '', 'Wi-Fi networks (up to 5)');
  const list = el('div', 'cp-mono', (s.networks ?? []).map((n) => n.ssid).join('\n') || 'none yet');
  const ssid = el('input'); ssid.placeholder = 'network name';
  const psk = el('input'); psk.placeholder = 'password'; psk.type = 'password';
  const add = el('button', 'cp-btn', 'ADD'); add.style.padding = '10px';
  add.onclick = async () => {
    if (!ssid.value.trim()) return;
    add.textContent = 'ADDING…';
    await api.setNetworks({ list: [{ ssid: ssid.value.trim(), psk: psk.value }] }); ssid.value = ''; psk.value = ''; await refresh();
  };
  nets.append(list, ssid, psk, add); p.append(nets);
  const tok = el('label', '', 'Device token');
  const rot = el('button', 'cp-btn ghost', 'ROTATE TOKEN'); rot.style.padding = '10px';
  const out = el('div', 'cp-mono', 'Rotating disconnects the badge until you send it the new token over USB.');
  rot.onclick = async () => { if (!confirm('Rotate the device token?')) return; const r = await api.rotateToken(); out.textContent = `Run in the serial console:\nD ${r.token}`; };
  tok.append(rot, out); p.append(tok);
  return p;
}
function render(s) {
  if (!s) return; last = s;
  wrap.replaceChildren(header(s), ...(view === 'chat' ? [feedView(s), inputBar()] : [settingsView(s)]));
}
async function refresh() { try { render(await api.state()); } catch { wrap.replaceChildren(el('div', 'cp-head', 'Could not reach the pet.')); } }
void refresh();
charming.onStateChange(() => { if (view === 'chat' && !sending) void refresh(); });
```

Set the app's `PET_SECRET` to the shared secret through the HTTP API, without printing it:
```bash
python3 - <<'EOF'
import json, os, urllib.request
token = open(os.path.expanduser("~/.config/charming/user-token")).read().strip()
app = open("app/charm-pet/APP_ID").read().strip()
secret = open("backups/app-shared-secret").read().strip()
req = urllib.request.Request(f"https://charm.ing/app/{app}/secrets", method="POST",
  data=json.dumps({"name": "PET_SECRET", "value": secret}).encode(),
  headers={"Authorization": f"Bearer {token}", "Content-Type": "application/json"})
print(urllib.request.urlopen(req).status)
EOF
```
Expected: `200` or `201`. If the endpoint shape differs, check `create-app-secret` in the Charming API reference (`read_docs reference/operations/create-app-secret`).
